What Batchwell is

An application for Frappe {{ facts.frappe_version }} and ERPNext {{ facts.erpnext_version }} that adds the rules a spice and masala plant runs on and ERPNext does not model: which supplier lot went into which blend, whether a batch has been released by quality, how much blend survived the grinder, and which customers received stock from a lot you now need back.

It adds no second stock ledger and no second valuation. Receipts are Purchase Receipts, runs are Work Orders and Stock Entries, dispatch is a Delivery Note. Accounting behaves exactly as it does in ERPNext, because it is ERPNext.

Which guide do you want

If you are working a shift — receiving stock, releasing a batch, finishing a run, picking a delivery — the Operating manual is the only one you need.

If you are putting the app on a site for the first time, or a company is behaving oddly, start with the Administrator guide. It covers the company policy that everything keys off, and the handful of failures that look like bugs and are configuration.

If you are changing the code, the Developer reference has the module map, the document events, the HTTP surface and the house rules this repository is held to.

Looking for something to send a vendor or a customer? The capability document is the short, outward-facing summary, and downloads as a PDF.
